 📊 FinSim – Stock Analyzer & Simulator

FinSim is a full-stack stock market simulation and analysis platform that allows users to track stocks, manage watchlists, perform simulated buy/sell actions, and view visual insights on market trends. It also includes a dedicated admin dashboard to manage stock data and monitor user activity.


 🚀 Project Highlights

📈 Real-time simulation of stock buy/sell actions  
📋 User registration, login, and personalized dashboards  
⭐ Watchlist functionality to track favorite stocks  
📊 Interactive charts and market trend visualizations  
🛠️ Admin module to add, update, or delete stock data  
🔐 Authentication and access control for admin/user roles  
💬 Feedback system for user input



🛠️ Tech Stack

Technologies   used                       

Frontend     | React, Bootstrap, HTML, CSS, JavaScript 
Backend      | Python (Flask)                        
 Database    | MySQL                                 
 Others      | Chart.js / ApexCharts (for graphs), XAMPP (for local hosting)
